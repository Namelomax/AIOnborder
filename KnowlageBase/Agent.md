# Agent.md — Инструкция по управлению базой знаний

Этот файл объясняет как устроена база знаний и как её обновлять.
Агент читает его чтобы понять структуру и правила работы с файлами.

## Структура базы знаний

```
KnowlageBase/
│
├── Agent.md              ← этот файл, инструкция по работе с KB
├── Index.md              ← оглавление всех разделов со ссылками
│
├── Компания.md           ← о компании, миссия, история, цифры
├── Структура команды.md  ← отделы, роли, кто за что отвечает
├── Процессы.md           ← рабочие процессы, инструменты, ритмы
├── Корпоративная культура.md ← ценности, традиции, неформальные правила
├── Учебный план.md       ← план адаптации новичка по неделям
├── Добро пожаловать.md   ← первое сообщение новому сотруднику
│
├── Тренеры/              ← материалы для тренеров (методички, программы)
│   ├── README.md         ← описание раздела
│   └── ...
│
└── Ученики/              ← персональные данные учеников (ограниченный доступ)
    ├── README.md
    └── ...
```

## Правила для каждого файла

### Обязательные поля (в начале любого md-файла)

```markdown
# Название сущности

**Тип:** [Компания / Процесс / Сотрудник / Документ / ...]
**Обновлено:** ГГГГ-ММ-ДД
**Автор:** Имя

---
```

### Ссылки между файлами

Для ссылки на другой документ используй формат Obsidian:
```
[[Название файла]]
```

Агент умеет читать эти ссылки через инструмент `read_file`.

## Как обновлять базу знаний

1. Редактируй файлы в Obsidian или любом текстовом редакторе
2. Коммить изменения в git: `git add . && git commit -m "обновил Компания.md"`
3. Пуш в репозиторий: `git push`
4. Агент получит обновления автоматически (читает файлы с диска)

## Что добавлять в базу

- Факты о компании, команде, процессах
- Ответы на часто задаваемые вопросы новичков
- Инструкции по инструментам и рабочим процессам
- Контакты ответственных по каждому направлению
- Неформальные правила и традиции команды

## Чувствительные данные

Персональные данные сотрудников, зарплатная информация и конфиденциальные
документы должны храниться в папке `Ученики/` с ограниченным доступом.
Агент не имеет доступа к этим папкам по умолчанию (контролируется через MCP).
