# Раздел: Тренеры

**Тип:** Раздел базы знаний
**Доступ:** Тренеры и выше

Здесь хранятся материалы для тренеров: методички, программы обучения,
технологии онбординга, чек-листы уроков и история по каждому тренеру.

## Структура раздела

```
Тренеры/
├── README.md              ← этот файл
├── Технология онбординга.md  ← процесс обучения нового ученика
├── Программы/             ← учебные программы по направлениям
└── История/               ← чек-листы и история уроков по тренерам
```

## Как заполнять историю уроков

После каждого урока тренер заполняет чек-лист в папке `История/`:

```
История/
└── Имя Тренера/
    └── ГГГГ-ММ-ДД_Имя Ученика.md
```

### Шаблон чек-листа урока

```markdown
# Урок: [Тема]

**Дата:** ГГГГ-ММ-ДД
**Тренер:** Имя
**Ученик:** Имя
**Этап онбординга:** 1-10

## Пройдено
- [ ] Тема 1
- [ ] Тема 2

## Обратная связь
Что прошло хорошо:

Что улучшить:

## Следующий урок
Тема:
Дата:
```
