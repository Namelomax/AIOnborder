# Учебный план — Адаптация нового сотрудника

## Цель онбординга

За первые **90 дней** ты должен:
1. Понять продукт изнутри (сам пройти часть курса как студент)
2. Разобраться в процессах и инструментах команды
3. Сделать свой первый полноценный вклад в продукт
4. Познакомиться с ключевыми людьми

---

## Первая неделя — Ориентация

**Цель:** Не потеряться, понять основное.

### День 1
- [ ] Встреча с HR (Мария Попова) — бумаги, доступы, оборудование
- [ ] Встреча с прямым руководителем — план на испытательный срок
- [ ] Регистрация в Slack, Notion, Linear, GitHub (если нужен)
- [ ] Прочитай [[Компания]] и [[Корпоративная культура]]

### Дни 2–3
- [ ] Записаться на демо продукта у Product-менеджера
- [ ] Пройти первый модуль любого курса как студент — **обязательно**
- [ ] Познакомиться с командой в Slack: напиши в `#general` кто ты и откуда

### Дни 4–5
- [ ] Изучи [[Процессы]] — как работает твоя команда
- [ ] Первый standup с командой
- [ ] Первая задача (небольшая, реальная — не «сделай hello world»)

---

## Первый месяц — Погружение

**Цель:** Понять продукт, начать делать реальные задачи.

### Неделя 2
- Shadowing: смотришь как работают коллеги в твоей роли
- Читаешь документацию по своему направлению (в Notion)
- Берёшь задачи под присмотром ментора

### Неделя 3–4
- Работаешь самостоятельно, ментор консультирует
- Участвуешь в планировании спринта
- Проходишь один полный курс (или половину буткемп-программы)

**Checkpoint:** встреча с руководителем, обсуждение первого месяца.

---

## 60 дней — Самостоятельность

**Цель:** Полная самостоятельность в задачах своей роли.

- Ведёшь задачи без ментора
- Участвуешь в ретро и планировании как полноправный участник
- Предлагаешь улучшения (приветствуется!)
- Если разработчик — делаешь код-ревью для коллег

---

## 90 дней — Первый результат

**Цель:** Сделал что-то, чем можно гордиться.

- Закрыл значимую задачу / фичу / проект
- Провёл или участвовал в мини-презентации на Friday Demo
- Встреча с руководителем: оцениваем испытательный срок

## Треки по ролям

### Разработчик (Frontend/Backend/Fullstack)

**Стек:**
- Frontend: React, TypeScript, Next.js, TailwindCSS
- Backend: Node.js, PostgreSQL, Redis, Docker
- CI/CD: GitHub Actions, Vercel/Railway

**Что изучить в первый месяц:**
1. Архитектура платформы (схема в Notion → «Architecture Overview»)
2. Local development setup (README в основном репо)
3. Процесс код-ревью и PR-описания
4. Наши соглашения по коду (ESLint конфиг + Prettier)

**Ключевые контакты:** Дмитрий Козлов (CTO), Артём Петров (тимлид frontend)

### Куратор / Методист

**Что изучить:**
1. Методология курса (Notion → «Педагогический подход»)
2. LMS: как создавать и редактировать уроки, задания, тесты
3. Как работает проверка заданий и обратная связь студентам
4. Портал поддержки студентов (Intercom)

**KPI куратора:**
- Время ответа студенту < 4 часов
- NPS группы > 70
- % трудоустроенных выпускников

**Ключевые контакты:** Ирина Соколова (CPO), Наталья Фёдорова (Head of Education)

### Маркетинг / Контент

**Что изучить:**

2. Tone of Voice документ (Notion → «Бренд»)
3. Контент-план и редполитика
4. Аналитика: Яндекс.Метрика, AmoCRM

**Ключевые контакты:** Алексей Морозов (CEO, сам ведёт контент), Светлана Громова (CMO)
